# Chibi Mafia Boss 🎩

Чиби-питомец мафиозного босса для рабочего стола SillyTavern. Живёт на твоём экране, гуляет, работает, нервничает и играет с тобой в игры.

## Возможности

- **Живое поведение**: босс гуляет по экрану, курит, звонит, нервничает при высоком стрессе
- **Системы привязанности и стресса**: гладь его, чтобы снизить стресс и повысить привязанность
- **Рабочий стол**: отправляй босса работать, смотри календарь со статистикой
- **Игры**: крестики-нолики и шашки с тремя уровнями сложности
- **Коллекция подарков**: разблокируй 25 подарков, выполняя условия
- **Письма и комментарии**: босс пишет тебе письма (с подключённым API) и комментирует твой RP
- **Звук и анимация**: пиксель-арт анимации и озвучка действий

## Установка

1. Открой SillyTavern → **Extensions** → **Install extension**
2. Вставь ссылку:
   ```
   https://github.com/ТвойНик/chibi-mafia-boss
   ```
3. Нажми **Save** — расширение установится автоматически
4. Перезагрузи страницу

## Настройка

- Открой **Extensions** → найди **Chibi Mafia Boss**
- Включи персонажа, задай имя, выбери темп поведения
- Включи рабочий стол (по желанию)
- Для писем и комментариев подключи API (OpenAI-совместимый или основной профиль ST)

## Управление

- **ПКМ** на боссе → круговое меню (погладить, играть, работа, подарки, письма)
- **ЛКМ** и тащи → перемещение босса
- **Календарь** на столе → статистика (привязанность, стресс, время онлайн)
- **Стол** можно таскать даже во время работы босса

## API (опционально)

Расширение работает без API, но с ним босс:
- Пишет тебе письма (отсылки к играм, RP и своему состоянию)
- Комментирует твою ролевую (с тремя характерами: спокойный, собственнический, одержимый)
